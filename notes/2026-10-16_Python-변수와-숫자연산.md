## 1. 핵심 개념

### 변수와 연산

- `=` : 변수에 값을 할당
- `/` : 나눗셈, 결과는 `float`
- `*` : 곱셈
- `-` : 뺄셈
- 연산식에 고정 숫자를 반복하기보다 변수를 재사용하면 유지보수에 유리하다.

### 변수 명명 규칙

Python에서는 PEP 8에 따라 `snake_case`를 권장한다.

- 권장: `correct_answer`
- 비권장 관례: `correctAnswer`

### f-string 출력

`f"문자열 {변수}"`를 사용해 변수 값을 문자열에 삽입한다.

`{변수:.1f}`는 숫자를 소수점 아래 한 자리까지 표시한다.

## 2. 실습 — CBT 시험 점수 계산기

```python
question = 40
correct_answer = 27
wrong_answer = question - correct_answer

correct_ratio = correct_answer / question * 100

scaled_score = correct_answer * (100 / question)
score_to_pass = 70
lack_score = score_to_pass - scaled_score

print(f"전체 문항: {question}개")
print(f"정답 문항: {correct_answer}개")
print(f"오답 문항: {wrong_answer}개")
print(f"정답률: {correct_ratio:.1f}%")
print(f"환산 점수: {scaled_score:.1f}점")
print(f"합격까지 필요한 점수: {lack_score:.1f}점")
```

**실행 결과**

```text
전체 문항: 40개
정답 문항: 27개
오답 문항: 13개
정답률: 67.5%
환산 점수: 67.5점
합격까지 필요한 점수: 2.5점
```

※ 합격 기준 70점은 실습용 가정이다.

## 3. 코드 리뷰에서 배운 점

1. `snake_case`를 사용해 Python 코드의 일관성을 유지한다.
2. `100 / question`처럼 변수를 활용하면 문항 수 변경에 유연하게 대응할 수 있다.
3. 합격 기준처럼 변경 가능한 값은 별도 변수로 관리한다.
4. `:.1f`로 출력 형식을 제어할 수 있다.

## 4. 추가로 발견한 문제

**① 합격 점수 초과 시 음수 출력**

```python
lack_score = max(0, score_to_pass - scaled_score)
```

`max()`를 사용하면 부족 점수가 음수로 출력되는 문제를 방지할 수 있다.

**② 전체 문항이 0일 때 오류 발생**

`question = 0`이면 `ZeroDivisionError`가 발생한다.

향후 조건문과 예외 처리를 배우면서 해결할 예정이다.
