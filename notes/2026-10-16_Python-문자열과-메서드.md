## 1. 문자열 인덱싱과 슬라이싱

- 인덱스는 왼쪽에서 `0`, 오른쪽에서는 `-1`부터 시작한다.
- `text[start:end]`는 시작 위치를 포함하고 끝 위치를 제외한다(반열린 구간).
- 길이는 `end - start`이고, `text[:3]`과 `text[3:]`으로 겹침 없이 나눌 수 있다.
- `text[-1]`은 마지막 문자, `text[-4:]`는 마지막 4문자를 가져온다.
- 범위를 벗어나는 단일 인덱싱은 `IndexError`를 발생시키지만 슬라이싱은 가능한 범위만 반환한다.

## 2. 문자열 처리 메서드

| 표현 | 의미 |
| --- | --- |
| `text.strip()` | 양끝 공백 제거 |
| `text.lstrip()`, `text.rstrip()` | 왼쪽, 오른쪽 공백 제거 |
| `text.split("-")` | 하이픈 기준 분할, 결과는 리스트 |
| `text.lower()` | 소문자로 변환 |
| `text.replace(" ", "")` | 문자열 안의 일반 공백 제거 |
| `int("0042")` | 정수 `42`로 변환(앞의 0은 사라짐) |

문자열은 불변(`immutable`)이므로 `strip()` 등은 원본을 직접 수정하지 않고 결과 문자열을 반환한다.

## 3. 함수와 메서드, 인수와 매개변수

- `print(text)`, `len(text)`, `int(value)`: 함수 호출.
- `text.strip()`, `text.split("-")`: 객체에 연결된 메서드 호출.
- `()`는 함수/메서드를 **호출**한다. 빈 괄호 자체가 `self`를 뜻하지는 않는다.
- **매개변수(parameter):** 함수 정의에서 입력을 받는 이름.
- **인수(argument, 인자라고도 함):** 호출 시 실제로 전달하는 값.
- 일반적인 인스턴스 메서드에서는 `obj.method()` 호출 시 객체가 첫 매개변수(관례적으로 `self`)로 자동 전달된다.
- `str.strip(text)`와 `text.strip()`은 동일한 문자열 처리 결과를 만든다.

```python
def greet(name):  # name: 매개변수
    print(name)

greet("Kim")      # "Kim": 인수
```

## 4. CBT 식별자 실습과 코드 리뷰

### 직접 작성한 첫 시도

```python
question_code = "  AIPOT-2026-0042  "
text = strip(question_code)  # NameError: 문자열 메서드는 객체를 통해 호출해야 함
slice = split(text, "-")     # 마찬가지로 메서드 호출 방식 오류
number = slice[2][2:4]
```

### 피드백을 반영한 참고 코드 (직접 작성 완료로 간주하지 않음)

```python
question_code = "  AIPOT-2026-0042  "
text = question_code.strip()
parts = text.split("-")
number = int(parts[2])

print(f"시험명: {parts[0].lower()}")
print(f"출제 연도: {parts[1]}")
print(f"문제 번호: {number}")
```

출력: `aipot`, `2026`, `42`. `slice`는 내장 이름과 겹치므로 변수명으로 `parts`를 권장한다.
